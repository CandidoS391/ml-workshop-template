# Getting started

Replace this checklist with instructions specific to your project as decisions are made.

1. Create a repository from this template using GitHub's **Use this template** option, if available, or copy the files you want.
2. Update the README with your question, learning objectives, and agreed deliverables.
3. Choose data, methods, and tools that fit your scope and available time.
4. Document how to access the data and run the work, including any setup or software versions needed.
5. Agree on team responsibilities and how you will share progress and review results.

Rename, replace, or remove any files or directories you do not need. If sharing this
repository as a GitHub template, enable **Template repository** in its settings.
